# the_snake

Классическая игра «Змейка» на Python с использованием Pygame.

## Управление

- **↑** — вверх
- **↓** — вниз
- **←** — влево
- **→** — вправо
- **Закрыть окно** — выход из игры

## Правила

- Змейка движется по игровому полю и не может двигаться назад.
- При поедании яблока змейка увеличивается на 1 сегмент.
- Змейка проходит сквозь стены и появляется с противоположной стороны.
- При столкновении с собой игра начинается заново.

## Запуск

```bash
pip install -r requirements.txt
python the_snake.py
